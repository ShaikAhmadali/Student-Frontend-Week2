# Student REST API using Flask

## Project Description

This project is a RESTful API developed using Python Flask and SQLite.

It performs CRUD (Create, Read, Update and Delete) operations on Student records.

This project was developed as part of my Internship Week-1 Task.

---

## Technologies Used

- Python
- Flask
- Flask-SQLAlchemy
- SQLite
- Thunder Client

---

## Features

- Add Student
- View All Students
- View Student by ID
- Update Student Details
- Delete Student

---

## API Endpoints

### Create Student

POST /students

### Get All Students

GET /students

### Get Student by ID

GET /students/<id>

### Update Student

PUT /students/<id>

### Delete Student

DELETE /students/<id>
